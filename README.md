# 八字速查 · 你的出厂设置

单文件静态应用：输入生日 → 四柱排盘 + 日主五行人设 + 分享卡。

## 特性
- **零依赖**：无框架、无后端、无外部 JS/CSS，一个 `index.html` 全包含
- **确定性排盘**：干支历法/五虎遁/五鼠遁全部规则计算，无 LLM、零幻觉、不上传任何数据
- **验证锚点**：1893-12-26 辰时 → 癸巳 甲子 丁酉 甲辰（公认）；2000-01-01 → 戊午日（历表）
- **分享卡**：纯 Canvas 自绘 750×1000 图，长按保存
- **本地运行**：`python3 -m http.server` 或直接双击打开

## 部署
- Vercel：`vercel deploy`（自动识别静态站）
- Cloudflare Pages：连接 Git 仓库或 `npx wrangler pages deploy .`
- 任何静态托管（GitHub Pages / Netlify）皆可

## 免责
八字是传统历法文化，不是宿命。本工具用于文化科普与自我探索，不做吉凶断言。
